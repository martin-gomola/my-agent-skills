# Bundled fonts

- **Atkinson Hyperlegible** is used for body text and controls. Copyright Braille Institute of America, Inc.; SIL Open Font License 1.1. See [license](AtkinsonHyperlegible-OFL.txt) and [upstream project](https://github.com/googlefonts/atkinson-hyperlegible).
- **Barlow Condensed** is used for display and HUD scan headings. Copyright The Barlow Project Authors; SIL Open Font License 1.1. See [license](BarlowCondensed-OFL.txt) and [upstream files](https://github.com/google/fonts/tree/main/ofl/barlowcondensed).

Latin and Latin Extended WOFF2 subsets are self-hosted so the page does not request fonts from a third party.
